RAIL CONTROL V3.1 — ATUALIZAÇÃO DIRETA DA V3 ORIGINAL
========================================================

ARQUIVOS:
- index.html
- manifest.webmanifest
- sw.js

INSTALAÇÃO EM GITHUB PAGES:
1. Faça uma cópia de segurança dos arquivos da V3.
2. Substitua estes três arquivos na RAIZ do MESMO repositório GitHub Pages.
3. Aguarde a atualização do GitHub Pages e recarregue o aplicativo no iPhone.
4. Se a antiga interface continuar aparecendo, feche/reabra o app ou atualize a página no Safari.

O QUE FOI PRESERVADO:
- Garagem, Operação e Ajustes exatamente na estrutura da V3.
- Chaves de armazenamento 'rail-control-v3' e 'rail-theme': os dados locais da V3 permanecem, desde que o app seja aberto no mesmo endereço e contexto de armazenamento.
- Importação antiga da V2, renomear por toque longo, botões +/-10%, slider, modo escuro/claro/automático.
- Operação de locomotivas continua SIMULADA (não é DCC, não comanda diretamente os trilhos).

NOVA ABA ENERGIA:
- Dois comandos: Ligar / Desligar tomada inteligente Positivo PPW1001.
- Campo de configuração para o nome do Atalho iOS que liga a tomada e outro que desliga.
- Os nomes são guardados localmente na chave 'rail-control-energy-v3-1'.
- Os botões usam o URL scheme oficial da Apple 'shortcuts://run-shortcut?name=...'.
- Abrir o Atalho NÃO confirma que o comando foi recebido pela tomada.
- A aba SEMPRE indica 'Estado da tomada não verificado' em vez de mostrar falso estado ON/OFF.
- Ao ligar, exige confirmação para evitar energização inesperada dos trilhos.

COMO TENTAR VINCULAR À POSITIVO:
1. No app Positivo Casa Inteligente, confirme que a tomada já responde aos comandos normais.
2. Crie/teste duas CENAS separadas: uma para LIGAR, outra para DESLIGAR a tomada.
3. Verifique no app Atalhos do iPhone se o app Positivo oferece uma ação para executar cada cena.
4. SE isso estiver disponível, configure dois atalhos no iPhone e teste ambos diretamente.
5. Cadastre exatamente os mesmos nomes na aba Energia do Rail Control.
6. Teste os comandos pela nova aba com o Frateschi em zero e as locomotivas protegidas.

IMPORTANTE: Não foi possível confirmar uma ação do Positivo Casa Inteligente disponível para
Atalhos/Siri na versão e no modelo PPW1001. A nova interface não cria essa integração.
Se o aplicativo Positivo não expuser ações no Atalhos, os botões NÃO conseguirão controlar
fisicamente a tomada; será preciso manter o controle via aplicativo Positivo.
Não use o desligamento pela tomada como parada de emergência garantida: depende de rede,
servidor/aplicativo e execução do comando. Mantenha a tomada física acessível.
A tomada NÃO controla velocidade; o botão do Frateschi 5300 continua fazendo essa função.
